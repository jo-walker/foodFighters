# foodFighters

To Access the charityorg. You need to add a new charityorg to the database. Then You can login in the dashboard with the username and password. After that u will se a list of products on the main page that are available to be claimed. When u press the button "claim the product". You can go check in the inventory that the product quantity would be changed. 
There is an extra functionality "add an product" that lets you add an product for free(Menaing donating a product). 
If u add the product from that portal and then go check the inventory, you will see the price of the product will be free.
