# FoodFighters

## Instructions

### Adding All the Files

1. Open `GithubFiles/foodFighters-Andreaworking-fixAnugrah/FoodFighters` and leave this tab open.
2. Open `LocalFiles/FoodFighters` and leave this tab open.
3. Select and copy all the content inside `LocalFile/FoodFighter` and paste it into `GithubFiles/foodFighters-Andreaworking-fixAnugrah/FoodFighters`.
   ![File Transfer Image](https://github.com/user-attachments/assets/e7ff4eca-7953-44c5-8841-c680b6900193)
4. When prompted, click **Skip these files**.
   ![Skip Files Image](https://github.com/user-attachments/assets/d52deefe-d4b1-4c4b-baa2-6f11798647f5)
5. You can now close `LocalFiles/FoodFighters`. It is no longer needed.
   
### Needed Changes
1. Open 'GithubFile\foodFighters-Andreaworking-fixAnugrah\FoodFighters\nbproject\private\private.properties' and change the paths accordignly to your machine.
2. Open 'GithubFile\foodFighters-Andreaworking-fixAnugrah\FoodFighters\src\java\Database\Database.sql" and create the database in MySQL.
3. Open 'GithubFile\foodFighters-Andreaworking-fixAnugrah\FoodFighters\src\java\Utilities\DataSource.java" and insert your own values for DB, HOST and PASSWORD
